# Hook options

Use this prompt only after the moment and quote have been checked against the source.

```text
You are helping package one short-form clip.

Audience: [AUDIENCE]
Clip transcript: [VERIFIED CLIP TRANSCRIPT]
Main payoff: [PAYOFF]

Write:
1. Five short on-screen hooks.
2. Three possible spoken opening lines using only exact words from the transcript.
3. One sentence explaining how each hook connects to the payoff.

Do not invent facts, quotes, results, or drama. Flag any hook that makes a stronger claim than the clip supports.
```

Check every spoken option word for word against the source.
