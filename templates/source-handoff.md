# Source handoff

Send the file you want edited, not only a watch-page link.

## Message to the creator

Can you send the source file for this episode or stream? I need the version you want clipped, plus any separate clean audio, transcript, and speaker names. If you marked moments, include the first few words and which file your timestamps match. A short excerpt with some room before and after the moment is fine for the first sample.
