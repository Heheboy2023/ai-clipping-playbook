# AI-assisted output release checklist

- [ ] Source use is authorized.
- [ ] AI candidates were compared with the full source context.
- [ ] Names, numbers, quotes, and speaker labels were verified.
- [ ] Crop tracking and caption timing were reviewed throughout.
- [ ] Corrections are recorded in `ai-correction-log.csv`.
- [ ] A human watched the final file in full.
- [ ] No tool score or generated claim is presented as a performance guarantee.
