## Checks

- Does each takeaway say only what the source supports?
- Which rows are alternative titles for the same idea?
- Which visual claims need actual media review?
- Are transcript search times being mistaken for checked cut times?
- What distinct value does each remaining clip give the audience?
- What is the next action for each saved idea?

Record source words separately from your interpretation. Do not invent footage,
dialogue, performance, revenue, or an exact timestamp to fill an empty field.
