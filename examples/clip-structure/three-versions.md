# Raw, overedited, and clean

Use your Chapter 1 recording or another actual spoken source. No media is included in this worksheet. Patterns and tones cannot show these editorial differences.

1. **Raw:** make rough start/end cuts. Keep a copy.
2. **Too much:** spend only a few minutes adding two needless zooms, one crowded caption, and an overlong written hook. This version demonstrates distraction; it is not a delivery file.
3. **Clean:** tighten the start, correct captions, keep a calm crop, add one useful picture change, and end after the payoff.

Play the three exports at the same size and volume. Note what changed in the opening, crop, captions, movement, and ending. Keep the clean version only if it actually improves those points.
