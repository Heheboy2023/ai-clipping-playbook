# Business-model responsibilities

Every engagement should name who owns or verifies source rights, guest/music/brand assets, editorial approval, disclosures, destination access, metrics, payment, retention, and incident response.

An editor’s technical ability to obtain or transform a file is not authorization. A client instruction can still be incomplete. Use written scope and permission evidence, escalate ambiguity, and obtain qualified legal/accounting advice where needed.

Clipkit intentionally separates local production approval from publishing authority.
