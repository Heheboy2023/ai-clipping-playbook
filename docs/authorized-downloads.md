# Authorized source access

Prefer creator-supplied masters, platform exports provided by the owner, or transcripts/captions that can be retrieved without full video. Record the grant, scope, destinations, term, credit, music/guest issues, and evidence before access.

This repository provides `retrieve-metadata`, not a general media downloader. The command requires `--confirmed-authorized` and uses yt-dlp’s no-download metadata mode.

If a future authorized workflow genuinely requires a temporary source download, isolate it inside that project, preserve the transcript and retrieval record, then remove task-created source video and temporary derivatives after verification. Never delete user-owned media.

Authorization does not settle every question. Platform terms, copyright, publicity/privacy, music, sponsor obligations, and client contracts can require separate review.
